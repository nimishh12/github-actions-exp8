# Experiment 08: Automated Application Deployment

## Aim

To implement an automated deployment pipeline using GitHub Actions.

## Technologies Used

* GitHub
* GitHub Actions
* Python
* Docker
* Docker Hub

## Project Description

This project demonstrates the initial setup of a CI/CD pipeline using GitHub Actions. The workflow checks out the source code, configures Python, installs dependencies and performs a basic syntax check.

## Project Files

* `.github/workflows/deploy.yml` – Defines the automated workflow.
* `README.md` – Contains the project description.

## Planned Pipeline Stages

1. Source code checkout.
2. Dependency installation.
3. Application validation.
4. Docker image building and publishing.
5. Deployment to a target environment.

## Status

Initial GitHub Actions workflow prepared. Docker registry configuration and deployment verification are pending.
